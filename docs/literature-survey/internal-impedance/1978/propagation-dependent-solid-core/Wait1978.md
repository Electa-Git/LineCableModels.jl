# Wait propagation-dependent solid-core impedance

## Identity and source

| Field | Value |
| --- | --- |
| Family | Internal impedance |
| Geometry | Solid circular cable core of radius ``c_0``; concentric thin insulation and the exterior earth region are separate terms. |
| Calculated quantities | Propagation-dependent p.u.l. core impedance ``Z_a(\beta)`` and its good-conductor Bessel reduction |
| Earth structure | Not applicable. |
| Model and approximation | The parent expression retains longitudinal propagation and conductor displacement current. The good-conductor reduction removes that dependence and uses the standard cylindrical Bessel ratio. |
| Main source | James R. Wait (1978) |
| Citation key(s) | `:Wait1978` |
| Evidence status | Original PDF equations (3), (8), and (9) checked |

**Description.** Wait separates the buried cable into core, axial insulation, and exterior terms. This record contains the core term.

**Assumptions.** The cable is circular and supports only axial current. The source uses the time factor ``\exp(+i\omega t)``. The reduced form assumes a good conductor and removes the retained ``\beta`` dependence.

**Expression.** Source equation (3) gives

```math
Z_a(\beta)=
\frac{i\sqrt{k_w^2-\beta^2}\,
I_0\!\left(i\sqrt{k_w^2-\beta^2}\,c_0\right)}
{2\pi(\sigma_w+i\epsilon_w\omega)c_0
I_1\!\left(i\sqrt{k_w^2-\beta^2}\,c_0\right)}.
\tag{3a}
```

For the good-conductor reduction, the source writes

```math
Z_i(\beta)=
\frac{1}{2\pi c_0}
\left(\frac{i\mu_w\omega}{\sigma_w}\right)^{1/2}
\frac{I_0(i k_w c_0)}{I_1(i k_w c_0)},
\qquad
k_w^2=-i\mu_w\omega(\sigma_w+i\epsilon_w\omega)
\simeq-i\mu_w\omega\sigma_w.
\tag{3b}
```

``I_0`` and ``I_1`` are modified Bessel functions. The square roots must use branches consistent with radial field decay and the source's ``\exp(+i\omega t)`` convention.

**Implementation.** Evaluate (3a) when longitudinal propagation or conductor displacement current must be retained. Evaluate (3b) under the good-conductor reduction. Stable scaled Bessel ratios may be needed for large arguments.

**Limitations.** This term excludes the insulation and exterior regions. It also excludes proximity effects and noncircular conductors.

**Reference.** [Wait1978](@cite), equation (3), printed p. 876.
