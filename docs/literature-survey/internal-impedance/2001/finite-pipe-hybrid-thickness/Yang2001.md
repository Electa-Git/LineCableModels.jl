# Yang–Ma–Dawalibi arbitrary-thickness pipe impedance

## Identity and source

| Field | Value |

| Family | Internal impedance |

**Description.** Hybrid analytical finite-wall pipe model intended to remain usable from thin to thick pipe walls.

**Assumptions.**

| Field | Treatment | Evidence |
| --- | --- | --- |
| Impressed longitudinal propagation constant ``Γ`` | Neglected in pipe diffusion solution. | Derivation. |
| Air propagation constant ``γ_air`` | Not applicable. | Internal pipe formula. |
| Earth propagation constant ``γ_earth`` | External ``Z_0`` is separate. | Assembly. |
| Earth permittivity and displacement current | Not part of pipe term. | Scope. |
| Range of validity | Parallel cables inside circular pipe of arbitrary wall thickness. | Title/abstract. |
| Earth permeability ``μ_earth`` | Not part of pipe wall term. | Scope. |
| Arrangement | Multiple cores at arbitrary locations inside a circular enclosure. | Geometry. |
| Earth structure | External ground contribution ``Z_0`` appended separately. | Assembly. |
| Conductor and insulation geometry | Circular pipe radii ``R_1,R_2`` and internal cable axes. | Figure 1. |
| Constitutive and field assumptions | Linear homogeneous pipe, cylindrical diffusion, harmonic fields. | (7). |
| Conventions | ``k`` is pipe propagation/diffusion constant. | Definitions. |

**Expression.**

```math
\mathbf Z=\mathbf Z_{SC}+\mathbf Z_p+\mathbf Z_0,
```

and the finite-wall input term is

```math
Z_{in}=\frac{j\omega\mu_0}{2\pi}\frac{\mu_0}{kR_1}
\frac{I_0(kR_1)K_1(kR_2)+K_0(kR_1)I_1(kR_2)}
{K_1(kR_1)I_1(kR_2)-I_1(kR_1)K_1(kR_2)}.
\tag{7}
```

The source then assembles ``Z_{pjk}=Z_{in}+Q_{jk}+C_n`` with the harmonic interaction terms in (9)–(12).

**Approximation.** Hybrid finite-pipe harmonic expansion; numerical truncation of ``n`` is required.

**Limitations.** The printed leading permeability normalization is retained verbatim and needs dimensional review before implementation.

**Reference.** [Yang2001](@cite), equations (7)–(12).

**Transcription source.** Original conference-page images.

## Source transcription

``Z_p`` is classified internal because it arises from pipe wall current, while ``Z_0`` remains external earth return.
