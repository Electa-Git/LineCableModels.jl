**Description.** Wise-form potential-coefficient approximation for an arbitrary horizontal earth stack represented by the same recursively homogenized propagation constant as the companion EHEM impedance.

**Assumptions.**

| Field | Treatment | Evidence |
| --- | --- | --- |
| Impressed longitudinal propagation constant ``Γ`` | Air-referenced through ``\gamma_n^2-\gamma_0^2``. | Stated — (A.39)–(A.40). |
| Air propagation constant ``γ_air`` | ``\gamma_0`` retained in every layer root. | Stated — (A.39)–(A.40). |
| Earth propagation constant ``γ_earth`` | Replaced by recursively calculated ``\gamma_{eq}``. | Stated — (8), Appendix A3. |
| Earth permittivity and displacement current | Retained in layer constants and in the coefficient denominator. | Stated — (8), (A.15). |
| Range of validity | Propagation-mode error reported below 5% to 1 MHz for tested cases; not a universal coefficient error bound. | Stated — conclusion and Appendix A6. |
| Earth permeability ``μ_earth`` | Recursion assumes vacuum permeability. | Stated — Appendix A3. |
| Arrangement | Overhead multiconductor; self/mutual potential entries. | Stated — Fig. 1 and (8). |
| Earth structure | Arbitrary horizontal ``N``-layer earth. | Stated — Appendix A3. |
| Conductor and insulation geometry | Infinite parallel round overhead conductors. | Stated — Fig. 1. |
| Constitutive and field assumptions | Linear isotropic layers; EHEM scalar homogenization; transmission-line model. | Stated — §II-B. |
| Conventions | Assemble ``P_e`` then apply ``Y_e=j\omega P_e^{-1}``; p.u.l. quantities. | Stated — (4), (8). |

**Expression.**

```math
P_{eij}\approx\frac{1}{2\pi\epsilon_0}
\left[\ln\left(\frac{D_2}{D_1}\right)
+2\int_0^{+\infty}
\frac{e^{-s(h_i+h_j)}\cos(sy_{ij})}
{(\gamma_{eq}^2/\gamma_0^2)s+\sqrt{s^2+\gamma_{eq}^2}}\,ds\right],
\qquad\text{(8)}
```

```math
\mathbf Y_e=j\omega\mathbf P_e^{-1}.
\qquad\text{(4)}
```

The ``\gamma_{eq}`` recursion is (A.36)–(A.40), transcribed in the companion impedance record.

**Approximation.** The layered electric interface response is replaced by one equivalent constant. The potential matrix is nevertheless assembled before inversion; no entrywise reciprocal is permitted.

**Limitations.** Nonmagnetic planar layers, infinite parallel overhead conductors, empirical validation domains and the TL approximation. This is not the exact four-layer ``G(s)`` expression.

**Reference.** [Xue2021](@cite), equations (4), (8), (A.36)–(A.40), PDF pp. 2, 8.

**Transcription source.** Accepted IEEE page images. The ``\gamma_{eq}^2/\gamma_0^2`` multiplier, root, factor two, logarithm and matrix inverse were visually verified.

## Source transcription

The source states that the EHEM removes the earlier Carson-assumption omission of earth permittivity and enables earth-return admittance. Its exact comparator is (5), not the electrostatic space potential alone.
