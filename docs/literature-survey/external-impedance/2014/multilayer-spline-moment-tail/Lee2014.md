# Lee–Zou multilayer spline-moment and asymptotic-tail evaluator

**Description.** Piecewise-cubic spline moment evaluation of the finite interval plus a closed exponential-integral tail for an arbitrary multilayer soil kernel.

**Assumptions.**

| Field | Treatment | Evidence |

**Expression.**

```math
Z_e=\frac{j\omega\mu_0}{2\pi}\int_0^\infty
F(\lambda)e^{-(h_1+h_2)\lambda}\cos(\lambda x)\,d\lambda.
\qquad\text{(2)}
```

The source recursively evaluates ``F`` by (4)–(9), applies cubic-spline moments on ``[0,T]`` by (14)–(19), and replaces the tail by

```math
F_{asy,N}=\frac1\lambda\left[1+\frac1{4\lambda^2}
\sum_{m=1}^{N-1}(\gamma_m^2-\gamma_{m+1}^2)e^{-2t_m\lambda}\right],
\qquad\text{(20)}
```

```math
Z_{asy}=\frac{j\omega\mu_0}{2\pi}\left[
\Re E_i(1,Tr_0)+\sum_{m=1}^{N-1}\frac{\gamma_m^2-\gamma_{m+1}^2}{4T}
\Re E_i(2,Tr_m)\right].
\qquad\text{(23)}
```

**Approximation.** Spline interpolation and asymptotic-tail truncation are numerical approximations to the parent integral.

**Limitations.** Horizontal stratification and thin overhead conductors; no independent conductor-internal term.

**Reference.** [Lee2014](@cite), equations (1)–(23).

**Transcription source.** Byline and displayed equations checked against original page images.
