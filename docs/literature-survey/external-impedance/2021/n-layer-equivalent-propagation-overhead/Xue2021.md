# Xue et al. N-layer EHEM overhead impedance

## Identification and source

| Field | Value |
| --- | --- |
| Family | External impedance |
| Geometry | Infinite parallel round overhead conductors. |
| Calculated quantities | Approximate self/mutual overhead earth-return impedance for arbitrary horizontal layers via one equivalent propagation constant |

| Main source | H. Xue, J. Mahseredjian, A. Ametani, J. Morales, and I. Kocar (2021) |

**Description.** Enhanced Equivalent Homogeneous Earth Method (EHEM): collapses an arbitrary layer stack into a recursively calculated equivalent air-referenced propagation constant and substitutes it into a Wise-type overhead impedance integral.

**Assumptions.**

| Field | Treatment | Evidence |
| --- | --- | --- |
| Impressed longitudinal propagation constant ``Γ`` | Air-referenced in ``\gamma_{en}=\sqrt{\gamma_n^2-\gamma_0^2}``. | Stated — (A.39)–(A.40). |
| Air propagation constant ``γ_air`` | ``\gamma_0`` retained through layer-root subtraction. | Stated — (A.39)–(A.40). |
| Earth propagation constant ``γ_earth`` | All ``\gamma_n`` enter the equivalent recursion. | Stated — (A.36)–(A.40). |
| Earth permittivity and displacement current | Retained in each layer bulk constant. | Stated — link to (A.15). |
| Range of validity | Reported maximum impedance error below 4% from 1 Hz to 5 MHz over tested models; this is empirical, not universal. | Stated — Appendix A6. |
| Earth permeability ``μ_earth`` | Equivalent recursion assumes vacuum permeability in the earth. | Stated — first paragraph of Appendix A3. |
| Arrangement | Overhead multiconductor, self and mutual. | Stated — Fig. 1 and (7). |
| Earth structure | Arbitrary ``N`` horizontal layers, terminal layer semi-infinite. | Stated — Appendix A3. |
| Conductor and insulation geometry | Infinite parallel round overhead conductors. | Stated — Fig. 1. |
| Constitutive and field assumptions | Linear homogeneous isotropic layers; EHEM replaces exact layer reflection by one equivalent constant. | Stated — §II-B. |
| Conventions | ``d_n`` are cumulative interface depths as printed; p.u.l. impedance. | Stated — Fig. 1 and (A.36)–(A.40). |

**Expression.**

```math
Z_{eij}\approx\frac{j\omega\mu_0}{2\pi}
\left[\ln\left(\frac{D_2}{D_1}\right)
+2\int_0^{+\infty}
\frac{e^{-s(h_i+h_j)}\cos(sy_{ij})}
{s+\sqrt{s^2+\gamma_{eq}^2}}\,ds\right].
\qquad\text{(7)}
```

The recursion begins

```math
\gamma_{eq}=\gamma_{e1}
\frac{\gamma_{e1}+\gamma_{eq2,3}-(\gamma_{e1}-\gamma_{eq2,3})e^{-2|d_1|\gamma_{e1}}}
{\gamma_{e1}+\gamma_{eq2,3}+(\gamma_{e1}-\gamma_{eq2,3})e^{-2|d_1|\gamma_{e1}}},
\qquad\text{(A.36)}
```

and repeats layerwise as (A.37)–(A.38), terminating with

```math
\gamma_{e,n}=\sqrt{\gamma_n^2-\gamma_0^2},\qquad n=1,\ldots,N.
\qquad\text{(A.39,A.40)}
```

**Approximation.** An exact layered reflection response is replaced by the scalar ``\gamma_{eq}``, after which a homogeneous-earth integral is evaluated. The recursion itself is explicit, but its physical homogenization is approximate.

**Limitations.** Assumes nonmagnetic earth layers and planar stratification. Accuracy figures apply only to tested profiles. Extreme complex contrasts and branch choices are not accompanied by formal stability/error guarantees.

**Reference.** [Xue2021](@cite), equations (7), (A.36)–(A.40), PDF pp. 2, 8.

**Transcription source.** Accepted IEEE page images. Factor two, denominator root, decay exponents, signs and terminal root definitions were visually verified.

## Source transcription

The intermediate ``\gamma_{eq2,3}``, ``\gamma_{eq3,4}``, … have the same fractional form printed in (A.37)–(A.38); the subscripts describe the remaining lower-layer stack.
