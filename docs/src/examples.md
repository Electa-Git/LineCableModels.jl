# Examples

The examples below demonstrate how to build the models of five cable systems and compute
their line parameters, from a single-core cable with a solid conductor to bipolar and
three-phase systems of armored cables. The last example gives the positive-sequence
parameters of a transposed three-phase line at the harmonics of the power frequency. Each
example is generated from an executable Julia script available in the `examples` folder of
the repository.
