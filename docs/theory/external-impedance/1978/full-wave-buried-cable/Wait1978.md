# Wait buried-cable full-wave external impedance

## Identification and source

| Field | Value |
| --- | --- |
| Family | External impedance |
| Geometry | Buried insulated thin cable with core radius ``c_0``, outer insulation radius ``c``, and burial depth ``h``. |
| Calculated quantities | Full-wave spectral external impedance ``Z_e(\beta)`` and low-frequency earth-return reduction |
| Earth structure | Homogeneous earth below air. |
| Model and approximation | The parent expression retains longitudinal propagation and displacement current in both media. The low-frequency form uses the source's stated good-ground and electrically thin limits. |
| Main source | James R. Wait (1978) |
| Citation key(s) | `:Wait1978` |
| Evidence status | Original PDF equations (5), (6), and (10)–(18) checked |

**Description.** The full-wave term relates the axial cable current to the exterior field in earth while retaining the air–earth interface. Wait then derives a low-frequency reduction for the dominant buried-cable mode.

**Parent expression.** Source equations (5)–(6) give

```math
Z_e(\beta)=-\frac{k^2-\beta^2}{2\pi(\sigma+j\omega\varepsilon)}
\left[
K_0\!\left(j\sqrt{k^2-\beta^2}\,c\right)
+\int_{-\infty}^{\infty}
R(\lambda,\beta)e^{-j\lambda c}
\frac{e^{-2uh}}{u}\,d\lambda
\right],
\qquad\text{(5)}
```

```math
\begin{aligned}
R(\lambda,\beta)&=-1+
\left[
\frac{1}{u+u_0}
-\frac{\beta^2}{k^2u_0+k_0^2u}
\right]
\frac{2k^2u}{k^2-\beta^2}, \\
u&=\sqrt{\lambda^2+\beta^2-k^2} \\
u_0&=\sqrt{\lambda^2+\beta^2-k_0^2} \\
k^2&=-j\omega\mu_0(\sigma+j\omega\varepsilon) \\
k_0^2&=\omega^2\mu_0\varepsilon_0.
\end{aligned}\qquad\text{(6)}
```

The branches of ``u`` and ``u_0`` tend to ``|\lambda|`` as ``\lambda\to\pm\infty``.

**Low-frequency form.** With the source's good-ground and small-``|\beta/k|`` reductions, equations (12)–(14) give

```math
\begin{aligned}
Z_e&=\frac{j\omega\mu_0}{2\pi}
\left[
K_0(jkc)+\frac{2}{\alpha}K_1(\alpha)+K_0(\alpha)
-\frac{2}{\alpha^2}(1+\alpha)e^{-\alpha}
\right] \\
\alpha&=2jkh,
\end{aligned}\qquad\text{(12)}
```

or, for ``kc\ll1``,

```math
Z_e=-\frac{j\omega\mu_0}{2\pi}
\left[\ln(0.89kc)+\frac{j\pi}{2}-T(\alpha)\right],
\qquad\text{(13)}
```

```math
T(\alpha)=K_0(\alpha)+\frac{2}{\alpha}K_1(\alpha)
-\frac{2}{\alpha^2}(1+\alpha)e^{-\alpha}.
\qquad\text{(14)}
```

**Implementation.** Use (5)–(6) in a full-wave modal solve. Use (12), or (13)–(14), only after applying the stated reductions. Couple this term to the core and jacket records through ``Z_a(\beta)+Z_e(\beta)=0``.

**Limitations.** The cable is thin, circular, infinite, and parallel to a planar interface. The parent derivation initially uses ``c\ll h``; the source discusses why the restriction can be relaxed in many low-frequency cases. Equations (12)–(14) do not retain the parent dependence on ``\beta``.

**Reference.** [Wait1978](@cite), equations (5)–(18), printed pp. 876–877.
