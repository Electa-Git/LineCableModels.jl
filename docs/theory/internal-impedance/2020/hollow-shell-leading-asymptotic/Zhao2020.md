# Zhao hollow-shell leading asymptote

## Identification and source

| Field | Value |
| --- | --- |
| Family | Internal impedance |
| Geometry | Homogeneous circular conducting annulus with 0<a<b. |
| Calculated quantities | Leading-asymptotic inner, outer, and transfer impedances |
| Earth structure | Not applicable. |
| Model and approximation | Large-argument Bessel approximation with geometric-mean radius in the transfer term. |
| Main source | H. Zhao, A. Ametani, A. Gole, and J. De Silva (2020) |
| Citation key(s) | Attributed source: `:Zhao2020`; equation witness: `:Ametani2021` |
| Evidence status | IET book page images checked, equations (A1.61)–(A1.65) and reference [90]. |

**Description.** The leading Bessel asymptotes give a separately selectable shell approximation.

**Expression.**

```math
Z_{ia}=\frac{\rho m}{2\pi a}\coth[m(b-a)].
\qquad\text{(A1.63)}
```

```math
Z_{ma}=\frac{\rho m}{2\pi\sqrt{ab}\sinh[m(b-a)]}.
\qquad\text{(A1.64)}
```

```math
Z_{oa}=\frac{\rho m}{2\pi b}\coth[m(b-a)].
\qquad\text{(A1.65)}
```

Here m²=jωμ/ρ, with the decaying root. Radii are in metres, resistivity in Ω·m, permeability in H/m, and impedances in Ω/m.

**Limitations.** The source derives these relations from large-argument Bessel functions. Finite evaluations at low frequency do not establish low-frequency accuracy. No curvature correction or core-proximity solution is included.

**Reference.** [Zhao2020](@cite), as reproduced in [Ametani2021](@cite) (Appendix A1.4.4, pp. 68–69).

**Numerical interpretation.** The evaluator shares the scaled hyperbolic factors with Wedepohl1973 while retaining these different radius factors and omission of the curvature corrections.
