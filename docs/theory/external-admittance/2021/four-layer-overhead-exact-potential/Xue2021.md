**Expression.**

```math
\mathbf Y_e=j\omega\mathbf P_e^{-1},
\qquad\text{(4)}
```

```math
P_{eij}=\frac{1}{2\pi\varepsilon_0}
\left[\ln\left(\frac{D_2}{D_1}\right)
+\int_0^{+\infty}G(s)e^{-s(h_i+h_j)}\cos(sy_{ij})\,ds\right],
\qquad\text{(5)}
```

```math
G(s)=F(s)+\frac{T'_1+T'_2T'_4}{T'_3}.
\qquad\text{(6)}
```

Here ``F(s)`` is (3) of the companion impedance record; ``T'_1,\ldots,T'_4`` and their nested factors are printed in (A.16)–(A.35), using the same roots (A.14)–(A.15).

**Approximation.** No fitted approximation is applied to (5); it is the source's exact four-layer potential entry within the selected longitudinal/TL model.

**Limitations.** Matrix inversion is indispensable. The printed coefficient is four-layer-specific and its appendix dependency graph is extensive. No insulation or conductor-internal admittance is included. Lateral variation and finite length are absent.

**Reference.** [Xue2021](@cite), equations (2)–(6), (A.14)–(A.35), PDF pp. 2, 7–8.

**Transcription source.** Accepted IEEE page images. Matrix inverse, ``1/(2\pi\varepsilon_0)``, logarithm, spectral factor and primed ``T`` combination were visually verified.

## Source transcription

The source explicitly calls the diagonal and off-diagonal ``P_{eij}`` entries the earth-return potential-coefficient matrix and then applies a single matrix inverse. Entrywise reciprocal interpretation is excluded.

## Numerical evaluation

The final publication prints the magnetic appendix as (10)–(24)
and the electric appendix as (25)–(44), on pp. 3841–3843.
The following elimination of those interface equations avoids growing
exponentials without changing the four-layer field model.
Here ``\lambda`` denotes the source's integration variable ``s``,
``g_n=\gamma_n^2``,
``a_n=\sqrt{\lambda^2+g_n-g_0}``, and
``\delta_n=d_n-d_{n-1}``, with ``d_0=0``.
The source depths ``d_n`` are positive cumulative distances.

Define the layer input and transmission functions

```math
\begin{aligned}
\mathcal U(a,w,\delta,b)&=
aw\frac{b+aw\tanh(a\delta)}{aw+b\tanh(a\delta)},\\
\mathcal T(a,w,\delta,b)&=
\frac{2aw e^{-a\delta}}{aw+b+(aw-b)e^{-2a\delta}}.
\end{aligned}
```

At ``a=0``, their continuous limits are
``\mathcal U=b/(1+b\delta/w)`` and
``\mathcal T=1/(1+b\delta/w)``.

Starting from ``B_4^{m}=a_4/\mu_4``, calculate upwards for
``n=3,2,1``:

```math
\begin{aligned}
B_n^{m}&=\mathcal U(a_n,1/\mu_n,\delta_n,B_{n+1}^{m}),\\
F&=\frac{2}{\lambda+\mu_0B_1^{m}}.
\end{aligned}
```

This ``F`` equals source equation (3). It is also the
permeability-weighted magnetic response used by the existing layered
impedance calculation, evaluated with the source's air propagation
reference. No second magnetic boundary solver is required.

For the electric correction, first propagate the normalized magnetic
potential from ``X_0=\lambda F`` through the three finite layers:

```math
X_n=\mathcal T(a_n,1/\mu_n,\delta_n,B_{n+1}^{m})X_{n-1},
\qquad n=1,2,3.
```

Set ``B_4^{e}=\mu_4a_4/g_4`` and ``C_4=0``.
For ``n=3,2,1``,

```math
\begin{aligned}
B_n^{e}&=\mathcal U(a_n,\mu_n/g_n,\delta_n,B_{n+1}^{e}),\\
C_n&=\mathcal T(a_n,\mu_n/g_n,\delta_n,B_{n+1}^{e})
\left[C_{n+1}+\mu_0\left(\frac1{g_n}-\frac1{g_{n+1}}\right)X_n\right].
\end{aligned}
```

The combined potential kernel is

```math
G=
\frac{F(B_1^{e}+\mu_0\lambda/g_1)-C_1}
{\mu_0\lambda/g_0+B_1^{e}}.
```

This is source equation (6), with its magnetic and electric terms
combined before subtraction. It retains the magnetic-potential forcing
at each interface; substituting a standalone electric reflection
coefficient would omit that coupling.

Only the stated four-layer overhead model is selected here, not an
arbitrary-layer admittance extension or the EHEM approximation.
Self coefficients use ``D_1=r_i``, zero lateral separation in the
image/integral terms, and ``D_2=2h_i``.
The layer integrals are evaluated adaptively. Potential coefficients
are assembled before the matrix inverse.
