# Wait electrically thin jacket axial impedance

## Identification and source

| Field | Value |
| --- | --- |
| Family | Insulation impedance |
| Geometry | Electrically thin concentric dielectric jacket ``c_0<r<c`` around a buried cable core. |
| Calculated quantities | Axial/modal p.u.l. series contribution of the insulation region |
| Earth structure | Not applicable. |
| Model and approximation | The thin-jacket expression is embedded in the propagation-dependent cable model and assumes ``\lvert k_c c\rvert\ll1``. It is distinct from the radial shunt admittance of the dielectric. |
| Main source | James R. Wait (1978) |
| Citation key(s) | `:Wait1978` |
| Evidence status | Original PDF equation (4) and its stated thin-insulation condition checked |

**Description.** The formula adds the axial series contribution of a concentric dielectric jacket to the core impedance in Wait's modal cable model.

**Expression.** Source equation (4) is

```math
\begin{aligned}
Z_a(\beta)&\simeq Z_j(\beta)
+\frac{\beta^2-k_c^2}{2\pi j\omega\varepsilon_c}
\ln\!\left(\frac{c}{c_0}\right) \\
k_c^2&=\omega^2\mu_0\varepsilon_c.
\end{aligned}\qquad\text{(4)}
```

Thus the insulation-region contribution is

```math
Z_{\mathrm{jns}}(\beta)=
\frac{\beta^2-k_c^2}{2\pi j\omega\varepsilon_c}
\ln\!\left(\frac{c}{c_0}\right).
```

**Implementation.** Evaluate ``Z_j(\beta)`` with the companion core record and add ``Z_{\mathrm{jns}}(\beta)`` before solving the modal equation. Preserve complex ``\varepsilon_c`` if dielectric loss is represented through permittivity.

**Limitations.** The source requires ``|k_cc|\ll1``. The expression is axial and propagation dependent; it is not the radial cable-insulation shunt admittance.

**Reference.** [Wait1978](@cite), equation (4), printed p. 876.
